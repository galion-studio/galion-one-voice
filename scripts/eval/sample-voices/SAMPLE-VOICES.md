# CC0 / public-domain sample voices

Galion Voice — Perpetual Open MIT License. (c) 2026 Maciej Grajczyk.

These four clips are the streaming demo's sample voices. They are not
Samantha or Jarvis, and they are not film audio. Piper does not use them
as a conditioning prompt. The live CPU voice is Piper
`en_US-ljspeech-medium`. The clips are here so a run can name a real
file it checked.

Fetched 2026-11-03 from the URLs below. The owner directed them as CC0 or
public domain. No owner WAV is in this directory.

| File | Source | Form |
|---|---|---|
| `pdx-voice.wav` | https://raw.githubusercontent.com/pdx-cs-sound/wavs/main/voice.wav | RIFF/WAVE PCM s16, mono, 48 kHz, as published |
| `armstrong-en.wav` | https://raw.githubusercontent.com/Vortiago/TapScribe/main/tests/fixtures/audio/armstrong-en.wav | RIFF/WAVE PCM s16, mono, 16 kHz, as published. Neil Armstrong's public-domain transmission. |
