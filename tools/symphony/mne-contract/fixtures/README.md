# Stand-in scenarios

Perpetual Open MIT License. (c) 2026 Galion Labs.

Eight invented moments for Galion One. Each one is an intent document and a read-back document on the 80 ms clock. There is no audio in this folder.

The feeling numbers are fixture knobs from `configs/symphony/mne-contract.toml` and from the trajectories in these files. They are not z-scores against a speaker, not decibels, and not litres. A Cowen name appears only as an optional pin. Neutral is the speaker baseline carried on each document, not a pin.

`galion-mne-contract fixtures` checks that every file decodes. The crate tests also round-trip each file through the binary and through JSON.
