The spelling is **Galion**. The product is Galion Voice.

The live frame is 80 ms. That is 12.5 Hz, 24 kHz, 1920 mono samples. `FRAME_MS` in `crates/galion-heartbeat` is 80. The same quantum is the bar for the live streaming sectors: a sector that rides the clock finishes inside the frame, and a late frame pauses.

The clock and the crate are [HEARTBEAT.md](HEARTBEAT.md). This page is the latency bar those sectors are scored against.

Inside one frame the non-inference work stays small. The budget for that work is [ONE-PERCENT.md](ONE-PERCENT.md): at or under 1% of the host, with tick work p99 well under 800 µs. Heavy speech, recognition, and the clone child run off the tick. Audio already in hand is pushed when it exists. The tick decides. It does not wait on a model.

Research synthesis for mouth-to-ear, desk numbers pending a measurement on this stack:

| Path | p50 | p95 | Where it is written |
|---|---|---|---|
| Web | ≤ 800 ms | ≤ 1,200 ms | [04-latency-streaming.md](../../research/galion-voice-v2/domains/04-latency-streaming.md) |
| PSTN, target | ≤ 900 ms | ≤ 1,300 ms | same |
| PSTN, first CI gate | ≤ 1,000 ms | ≤ 1,500 ms | [08-evaluation.md](../../research/galion-voice-v2/domains/08-evaluation.md) |

Those rows are targets. A number in [TTFA.md](TTFA.md) is a measurement only when its engine label says so. The virtual-user TTFA is loopback time until a whole reply WAV exists. It is not this frame, and it is not PSTN.

## Run

```bash
LIVE_REALTIME=1 scripts/run-live-demo.sh
cargo test --offline -p galion-heartbeat
```

`--realtime` sleeps 80 ms per frame so the wall clock and the frame match. The heartbeat tests cover a late frame: it is delivered paused, and the next frame does not catch up.

## Gate

**PASS** when a run records `frame_ms` 80 and the streaming-sector budget above is either measured on this machine or explicitly marked stub-measured in [SELF-EVAL.md](SELF-EVAL.md).

**FAIL** when a live sector blocks the tick, or when a late frame glitches ahead to make up time.

**BLOCKED** when the realtime demo has not been run on the machine being scored.
