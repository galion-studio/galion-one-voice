# Top ~20 Spoken Languages — Galion Voice Multilingual Plan

Status: research draft (W20-17, 2026-11-02, local only). Ranking = **total speakers (L1+L2)**, approximate,
based on Ethnologue-style figures (Ethnologue 2023–2025 editions). Figures are rounded and **vary by edition and
source** (Ethnologue vs. Wikipedia/CIA/national censuses) by ±10–20%, especially for L2 counts (English, Hindi,
French, Swahili, Indonesian) and for macrolanguage grouping (Arabic, Chinese, Persian). Not verified live this turn;
re-check against current Ethnologue before any public claim.

## Tiers
- **Tier 0 (now):** English — current English-only prototype.
- **Tier 1 (next):** Polish (owner language), Croatian (owner region / EU preference), plus EU-adjacent preference.
- **Tier 2 (later):** remaining top-20 languages, including major European ones (Spanish, French, German, Russian, Portuguese, Italian).

## Scope notes
- Hebrew (he/heb) is **not** in the global top 20 (~9–10 M speakers) and is therefore not listed. he-IL preference/locale-pack work is out of scope for this document.
- No locale packs are created here; this is a prioritisation table only.
- RTL scripts in Tier 2: Arabic, Urdu — need UI/TTS bidi handling when reached.
