# Archived Galion Research desk

The live web interface is the Galion Research app in galion-studio/hermes-research, for research.galion.app. GET /research on this host now serves a short notice. POST /research/ask and the other research routes stay here.

- research.html is the former desk.
- research-sound.spec.js is the Playwright suite that checked that desk's cues.
